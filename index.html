DrishtiPay

Hold a currency note up to the camera. The phone tells you how to move it.

Press Start camera, or Try demo.

Connect a trained model (optional)

Train image classes in Teachable Machine, one class per note (for example “₹100”), export it as TensorFlow.js, then paste the shared model link. This works when this page is hosted on your own site (GitHub Pages or Netlify). It may be blocked here.

Prototype. Camera frames stay in your browser and are never saved or sent. Positioning guidance is real; naming a denomination needs a trained model, and without one the page says so. It does not check whether a note is genuine. The demo mode is a simulation of the guidance, not note recognition. Voice commands use your browser’s speech recognition, which in Chrome sends audio to Google, so they need a connection.
